# Credits

UnifyWeb exists because other people did the hard work first. Thank you.

## Inspiration

- **[Solaar](https://github.com/pwr-Solaar/Solaar)** by Daniel Pavel and the Solaar contributors. The Linux device manager for Logitech receivers. Solaar's work on documenting HID++ helped make this project possible. UnifyWeb is a separate implementation written for the browser and contains no Solaar code.
- **Logitech Unifying Software** and **[Logi Web Connect](https://logiwebconnect.com)**. Logitech's own pairing tools, which UnifyWeb set out to replace and extend.
- **[libratbag](https://github.com/libratbag/libratbag)** and its contributors, whose documentation of gaming-mouse onboard profiles informed the profile editor.

## Protocol knowledge

The HID++ 1.0 and 2.0 protocols are implemented from publicly available information, including Logitech's published HID++ specifications and the community documentation maintained by the projects above.

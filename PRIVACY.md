# Privacy policy

Last updated: 29 October 2026

UnifyWeb does not collect, send, sell or share personal data. There are no accounts, analytics, advertising, cookies or tracking of any kind.

## What stays on your computer

UnifyWeb keeps a few things in your browser's local storage, on your computer only:

- **Settings you change** on each device, so they can be put back when the device reconnects.
- **Your rules.**
- **Your preferences**, such as the theme and whether to re-apply saved settings.

The protocol log on the Help page is kept in memory only and disappears when you close or reload the page.

To remove everything, clear this site's data in your browser's settings.

## Your devices

UnifyWeb can only talk to a receiver or device after you choose it in your browser's own permission window. Everything it sends and receives stays between your browser and that device. You can withdraw access at any time in your browser's site settings.

## Network requests

The app makes no requests to other websites: its fonts, icons, styles and code are all inside the page. When you use the hosted version, it fetches one small file from the same site, `version.json`, to tell you when a newer version is available. That file contains only the app's version number and build details.

## Hosting

The hosted version is served by GitHub Pages. Like any web host, GitHub receives standard request information such as your IP address and browser type when you load the page, and handles it under the [GitHub privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). UnifyWeb's maintainers do not receive these logs. If you open a downloaded copy of the file from your computer, no host is involved at all.

## Notifications and clipboard

UnifyWeb shows desktop notifications only if you allow them and a rule asks for one. It writes to your clipboard only when you click a Copy button.

## Changes

Any change to this policy will be published here, in the project's repository, with a new date at the top.
